# Решение проблем

## `ModuleNotFoundError: No module named 'telegram'` (или `whisper`, `librosa`, ...)

Зависимости не установлены в то окружение, из которого запускается бот. Активируйте `.venv` и выполните:

```bash
pip install -r requirements.txt
```

В VS Code проверьте, что выбран интерпретатор из `.venv`.

## `TELEGRAM_BOT_TOKEN is not set`

Нет файла `.env` или в нём пустой токен. Скопируйте `.env.example` в `.env`, впишите токен и **сохраните файл**.

## `InvalidToken: The token ... was rejected by the server`

В `.env` неверный токен, например остался шаблон `your_bot_token_from_botfather`. Впишите токен от BotFather.
Эта ошибка печатает токен в консоль: если лог кому-то показан, отзовите токен в BotFather.

## `ffmpeg not found on PATH`

Установите FFmpeg и добавьте его в `PATH`; проверьте командами `ffmpeg -version` и `ffprobe -version` в том же терминале,
из которого запускаете бота. После правки `PATH` перезапустите терминал.

## Бот пишет «Нет доступа»

Ваш Telegram ID не в `ALLOWED_USER_IDS`. Отправьте боту `/start`, он покажет ID. Впишите его в `.env`
(несколько ID через запятую) и перезапустите бота.

## Бот не отвечает в Telegram

1. Убедитесь, что `main.py` запущен и в логе есть строка `Bot started`.
2. Нет ли лишнего экземпляра (зависший, из отладчика)? Telegram отдаёт сообщения только одному процессу.
3. Ошибка `Conflict: terminated by other getUpdates request` значит, что бот запущен где-то ещё с тем же токеном.
4. Накопившиеся сообщения бот обработает сразу после запуска.

## «Telegram не даёт боту скачать файлы больше 20 МБ»

Ограничение облачного Bot API. Положите видео в `data/inbox` и выберите его через `/inbox`, либо отправьте ссылку,
либо поднимите локальный Bot API сервер (см. [DEPLOYMENT.md](DEPLOYMENT.md)).

## Шорт готов, но не пришёл в чат

Файл больше лимита отправки (50 МБ). Бот присылает путь к нему в `data/output/<имя>/`. Уменьшите длину шорта
или поднимите локальный Bot API сервер.

## Обработка очень медленная

- Whisper `medium` на процессоре медленный: `WHISPER_MODEL=small` или `base`.
- Хайлайт анализирует кадры по 2 в секунду, 30-минутное видео занимает несколько минут.
- Задачи идут по одной; следующие ждут в очереди (`/jobs`).

## «No dynamic moments found» или слишком короткий хайлайт

Видео слишком равномерное для выбранной чувствительности. Попробуйте другой алгоритм в панели
(`surprisal` для однородного фона, `attention` для смешанного контента) или режим «Нарезка».

## Субтитры не появились

- «no speech detected» — Whisper не нашёл слов в клипе.
- «no audio track» — в клипе нет звуковой дорожки.
- Язык определяется только как английский или русский; другой язык распознаётся как английский.

## Нет музыки в результате

В `data/music` нет файлов `.mp3`/`.wav`. Добавьте их файлом боту или в папку и проверьте `/music`.

## Не скачивается видео по ссылке

`yt-dlp` часто обновляется под изменения сервисов: `pip install -U yt-dlp`. Приватные и платные видео не поддерживаются.

## `UnicodeEncodeError` в консоли Windows

В `main.py` и `cli.py` вывод принудительно переводится в UTF-8. Если ошибка осталась, задайте переменную окружения
`PYTHONIOENCODING=utf-8`.

## Токен попал в логи

Библиотека `httpx` пишет URL запросов к Telegram, а в них есть токен. В `main.py` уровень логов `httpx` уже понижен до
`WARNING`. Если токен всё же засветился (лог, скриншот, чат), отзовите его в BotFather и замените в `.env`.
